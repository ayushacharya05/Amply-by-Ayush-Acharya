How to Install:

  1. Click the Download Extension button above to download the .zip archive.
  2. Extract the contents of the downloaded .zip file into a folder on your computer.
  3. Open your browser and navigate to the Extensions page:
    • For Chrome: Go to chrome://extensions/
    • For Brave: Go to brave://extensions/
  4. Enable Developer mode using the toggle switch (usually found in the top-right corner).
  5. Click on the Load unpacked button (top-left corner).
  6. Select the folder where you extracted the extension files.
